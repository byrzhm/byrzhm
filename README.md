### 🔭 About Me

I'm a CS graduate student at **BUPT**, working on **AI Infrastructure** — the systems layer that makes large-scale AI training and inference fast, efficient, and reliable.

My work sits at the intersection of high-performance computing and deep learning systems:

- ⚡ **GPU Kernels** — CUDA / Triton kernel optimization, memory hierarchy tuning
- 🏗️ **Training Systems** — distributed training, operator fusion, compiler backends
- 🚀 **Inference Efficiency** — attention kernels (FlashAttention), quantization, serving stacks
- 🔬 **Profiling & Analysis** — Nsight Compute, roofline modeling, bottleneck diagnosis
